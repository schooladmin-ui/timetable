## 1. 현재 저장 방식 설명 vs 제안하신 시트(탭) 추가 방식 비교

### ① 현재 구현된 방식 (`_PROJECTS_DB` 숨김 시트 JSON 저장)
- **구글 드라이브 폴더에 엑셀 파일을 저장하는 방식이 아닙니다.**
- 업로드된 `.xls` / `.xlsx` 파일을 브라우저에서 파싱한 후, 연결된 구글 스프레드시트 내부의 **`_PROJECTS_DB`라는 숨김 시트**에 압축된 JSON 문자열 형태로 저장하고 불러오는 방식입니다.
- **한계점**: 스프레드시트를 열었을 때 일반적인 시간표 표 형태로 보이지 않기 때문에, 업로드 후 일부 시간표를 스프레드시트에서 직접 눈으로 확인하거나 셀을 수정하기 어렵습니다.

### ② 제안하신 방식 (스프레드시트에 실제 시트 탭으로 추가하여 관리) — **권장**
- 사용자가 엑셀 파일 2개(주간시간표 + 교사시간표)를 업로드하고 학기 식별자(예: `2026-1` 또는 `202601`)를 지정하면, **연결된 구글 스프레드시트 안에 실제 시트(탭) 2개를 생성하여 원본 표 데이터를 그대로 기입**하는 방식입니다.
- **시트 이름 규칙 예시 (표준화 지원)**:
  - 통일된 하이픈 규칙: **`2026-1-주간시간표`** & **`2026-1-교사시간표`**
  - 또는 붙여쓰기/연월 규칙 모두 호환 인식: **`2026-1주간시간표`**, **`202601-교사시간표`**, **`2025-2-주간시간표`** 등
- **장점**:
  1. **스프레드시트 직접 편집 가능**: 업로드된 시간표가 구글 스프레드시트 탭으로 그대로 존재하므로, 학기 중 일부 수업/교사 변경 시 엑셀을 다시 업로드할 필요 없이 스프레드시트 셀만 고치면 웹앱에 즉시 반영됩니다.
  2. **시트 탭 기반 자동 학기 목록화**: 스프레드시트에 추가된 시트 탭 이름에서 접두어(`2026-1`, `2025-2` 등)를 자동으로 추출해 상단 드롭다운 메뉴에 학기 목록을 자동 구성합니다.
  3. **추가 Drive 권한 불필요**: 구글 드라이브 폴더 생성 권한(`DriveApp`) 없이 기존 `SpreadsheetApp` 권한만으로 동작합니다.

## 2. 세부 아키텍처 및 구현 계획

### Step 1. 시트 탭 명명 규칙 및 자동 세트 매칭 엔진 (`Code.gs`)
1. **시트 이름 패턴 파서 (`discoverSemesterProjectSets_`)**:
   - 스프레드시트 내 전체 시트 목록을 스캔하여 다음과 같은 패턴을 학기 프로젝트 세트로 자동 묶습니다:
     - 접두어 추출 정규식: `/^(.+?)[-_ ]?(주간\s*시간표|학급\s*시간표|반별\s*시간표|교사\s*시간표)$/`
     - 예:
       - `2026-1주간시간표` + `2026-1교사시간표` → 프로젝트 키 `2026-1`
       - `202601-주간시간표` + `202601-교사시간표` → 프로젝트 키 `202601`
       - 기본 `주간시간표` + `학급시간표`(`교사시간표`) → 기본 연동 시트 (`__DEFAULT__`)
2. **역할 자동 판별 (`parseSheetAutoLayout_`)**:
   - 시트 이름에 `주간시간표` / `학급시간표` / `교사시간표` 중 어떤 이름이 붙더라도 시트 내부의 블록/행·열 헤더(`1-1` 학급인지 `교사명`인지)와 시트명을 함께 분석하여 학급 시간표(`class`)와 교사 시간표(`teacher`)를 정확히 매핑하고 양방향 교차 보완(`crossEnrichTimetables_`)을 수행합니다.

### Step 2. 엑셀 업로드 시 스프레드시트에 새 시트(탭) 생성 및 기록 (`Code.gs` + `index.html`)
1. **클라이언트 (`index.html`)**:
   - 사용자가 학기 이름(예: `2026-1` 또는 `2026년 1학기` → 시트 접두어 `2026-1`)과 **주간시간표 파일**, **교사시간표 파일**을 선택하고 저장 버튼을 누르면:
     - SheetJS / HTML-XLS 파서로 추출한 2차원 배열(`rows: string[][]`) 2세트를 서버 `saveUploadedSheetsToSpreadsheet(prefix, weeklyRows, teacherRows)`로 전송합니다.
     -同時に 브라우저 인메모리에도 즉시 반영하여 대기 시간 없이 바로 화면을 전환합니다.
2. **서버 (`Code.gs` - `saveUploadedSheetsToSpreadsheet`)**:
   - 입력받은 접두어(예: `2026-1`)를 기반으로:
     - **`{접두어}-주간시간표`** (예: `2026-1-주간시간표` 또는 사용자 지정 형식) 시트 생성(이미 있으면 기존 시트 내용 덮어쓰기) 후 `sheet.getRange(1, 1, rows.length, maxCols).setValues(normalizedRows)`로 일괄 기록
     - **`{접두어}-교사시간표`** (예: `2026-1-교사시간표`) 시트 생성 후 동일하게 2차원 표 데이터 일괄 기록
   - 생성된 시트 세트를 `buildTimetablePayloadFromSheetPair_(weeklySheet, teacherSheet)`로 파싱하여 검증된 페이로드를 반환하고 활성 학기로 저장합니다.

### Step 3. 상단 드롭다운 연동 및 시트 삭제/관리 (`index.html` + `Code.gs`)
1. **상단 드롭다운 (`#projectSelect`)**:
   - 스프레드시트에서 감지된 학기 시트 세트 목록(예: `2026-1 (2026-1-주간시간표 · 2026-1-교사시간표)`)을 드롭다운 옵션으로 표시합니다.
   - 드롭다운에서 학기를 변경하면 해당 시트 탭 세트의 데이터를 즉시 불러와 렌더링합니다.
   - **[🔄 동기화]** 버튼을 누르면 현재 선택된 학기 시트 탭(예: `2026-1-주간시간표`, `2026-1-교사시간표`)을 스프레드시트에서 다시 읽어와 셀 수정 사항을 즉시 반영합니다.
