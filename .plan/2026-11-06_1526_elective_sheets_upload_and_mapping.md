## 2. 단계별 세부 구현 계획

### Step 1. `'시트 세트 관리'` 모달 UI 및 파일 업로더 확장 (`index.html`)
1. **모달 내 파일 선택 그리드(`.proj-files-grid`, 2×2 배열) 구성**:
   - `📅 [파일 1] 주간시간표 (.xls / .xlsx / .csv)` → `[20XX-X주간시간표]`
   - `🏫 [파일 2] 학급시간표 (.xls / .xlsx / .csv)` → `[20XX-X학급시간표]`
   - `📘 [파일 3] 선택과목2학년 (.xls / .xlsx / .csv)` → **`[20XX-X선택과목2학년]`** (`id="boxElective2File"`, `id="fileElective2Input"`)
   - `📗 [파일 4] 선택과목3학년 (.xls / .xlsx / .csv)` → **`[20XX-X선택과목3학년]`** (`id="boxElective3File"`, `id="fileElective3Input"`)
2. **생성될 시트명 미리보기(`updateSheetNamePreview_`) 및 학기 목록 메타 표시 연동**:
   - 년도·학기(예: `2026-2`) 선택 시 미리보기에 `[2026-2주간시간표] · [2026-2학급시간표] · [2026-2선택과목2학년] · [2026-2선택과목3학년]`을 표시합니다.
   - 하단 `스프레드시트 내 학기별 시트 목록`(`renderSavedProjectsList_`)에서도 선택과목 시트 연동 여부를 함께 표시합니다.
3. **CSV / XLS / XLSX 통합 리더 보강 (`readExcelFileToSheetsAsync_`)**:
   - `.csv` 파일 업로드 시 UTF-8 및 EUC-KR(CP949) 인코딩을 자동 감지하여 한글 깨짐 없이 2차원 배열(`rows`)로 정확히 파싱하는 CSV 파서를 내장합니다.
4. **선택과목 단독 추가/업데이트 지원 (`saveAndLoadUploadedProject`)**:
   - `state.pendingFiles`에 `{ weekly, classFile, elective2, elective3 }` 4개 슬롯을 관리합니다.
   - 만약 사용자가 `weekly`/`classFile` 없이 **`elective2` 또는 `elective3` 파일만 선택한 경우**, 현재 학기(예: `2026-2`)의 기존 `weekly`/`class` 데이터를 유지하면서 선택과목 시트만 스프레드시트에 저장(`saveSemesterSheetsToSpreadsheet`)하고 즉시 매칭 결과를 화면에 반영합니다.

### Step 2. 백엔드 시트 관리 및 선택과목 파서 구현 (`Code.gs` & `index.html`)
1. **시트 세트 자동 탐색 (`discoverSemesterSheetSets_`, `buildTimetablePayloadFromRealSheets_`)**:
   - `<prefix>선택과목2학년` (예: `2026-2선택과목2학년`) 및 `<prefix>선택과목3학년` (예: `2026-2선택과목3학년`) 시트를 자동 인식합니다.
   - `saveSemesterSheetsToSpreadsheet(requestJson)`에서 `elective2Rows`, `elective3Rows`가 전달되면 각각 `<prefix>선택과목2학년`, `<prefix>선택과목3학년` 시트를 생성/업데이트합니다.
   - `deleteSemesterSheetsOnServer(prefixInput)` 실행 시 해당 학기의 선택과목 시트도 함께 정리합니다.
2. **선택과목 표 파서 (`parseElectiveSheetRows_`)**:
   - 1행에서 그룹 헤더(`A`, `B`, `C`, `D`, `E`, `F`)의 열 위치를 감지하고, 각 그룹의 3열(`[과목, 교사, 강의실]`) 데이터를 파싱합니다.
   - 하단 강의실 정원 요약 행(`301호, 302호... / 30, 21...`)은 자동 제외합니다.
   - **복합 요일 분담 수업 파싱**:
     - 예: `"환경, 논술"` / `"김진비, 이수연(화)"` / `"405호"` → 화요일(`dayIdx=1`)은 `{ s: '논술', t: '이수연', r: '405호' }`, 그 외 요일은 `{ s: '환경', t: '김진비', r: '405호' }`
     - 예: `"중국문화, 논술"` / `"김영애, 박인태(월)"` / `"211호, 401호"` → 월요일(`dayIdx=0`)은 `{ s: '논술', t: '박인태', r: '401호' }`, 그 외 요일은 `{ s: '중국문화', t: '김영애', r: '211호' }`
     - 예: `"프로그래밍*, 논술"` / `"양진모, 박두울(목)"` / `"정보실, 315호"` → 목요일(`dayIdx=3`)은 `{ s: '논술', t: '박두울', r: '315호' }`, 그 외 요일은 `{ s: '프로그래밍*', t: '양진모', r: '정보실' }`

### Step 3. 강의실 ↔ 학급(2·3학년) 및 특별실 매칭 엔진 (`applyElectiveClassroomMapping_`)
1. **강의실 코드 정규화**:
   - **2학년**: `301호`~`309호` ⇔ `2-1`~`2-9` (`2학년 1반`~`2학년 9반`), 특별실 = `211호`, `416호`, `정보실`, `314호`
   - **3학년**: `401호`~`409호` ⇔ `3-1`~`3-9` (`3학년 1반`~`3학년 9반`), 특별실 = `211호`, `315호`, `정보실`
2. **요일·교시별 선택과목 그룹(`A`~`F`) 판별**:
   - 각 `(요일, 교시)`에 대해 2학년(`2-1`~`2-9`) 및 3학년(`3-1`~`3-9`) 수업에 배정된 과목 접두사(`A_`, `B_`, `D_영문`, `선택A` 등)와 교사 집합을 선택과목 시트의 `A`~`F` 그룹과 대조하여 해당 교시의 선택과목 그룹을 정확히 식별합니다.
3. **학급 시간표(`classes`) 및 교사 시간표(`teachers`) 동시 보정**:
   - **학급 시간표 (`2-1`~`2-9`, `3-1`~`3-9`)**:
     - 해당 교시에 그 교실(`301호`~`309호`, `401호`~`409호`)에서 실제로 진행되는 선택과목명(예: `[A] 언어생활탐구#`)과 담당 교사명(예: `윤성현`)을 배정합니다.
     - 해당 타임에 특별실(`정보실`, `211호`, `416호`, `315호` 등)로 이동하여 본 교실이 비는 학급(예: 2학년 A타임의 `302호(2-2)`, `304호(2-4)`)은 잘못된 가배정 과목/교사를 지우고 이동수업 공실로 처리합니다.
   - **교사 시간표 (`teachers`)**:
     - 선택과목 담당 교사의 해당 교시 슬롯에 정식 선택과목명과 실제 강의실(`2-1(301호)` 또는 `정보실`, `211호`, `416호`, `315호`)을 정확히 기록합니다.
   - **수업 교사 찾기 (`teaching` 모달 `3 × n` 그리드)**:
     - 2학년·3학년 각 학급 셀(`2-1`~`2-9`, `3-1`~`3-9`)에 실제 그 교실에서 수업하는 교과명과 교사명이 표시되며, 해당 교시에 특별실(`211호`, `315호`, `416호`, `정보실` 등)에서 진행되는 선택과목 수업도 모달에서 함께 확인·검색할 수 있도록 표시합니다.
