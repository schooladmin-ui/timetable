## 2. 세부 설계 및 구현 계획

### Step 1. 스프레드시트 `'2026-2교사그룹'` 시트 파싱 및 저장 API 구현 (`Code.gs`)

1. **학기별 교사그룹 시트명 규칙 (`getTeacherGroupSheetName_(prefix)`)**
   - 활성 학기 접두어(`targetPrefix`, 예: `'2026-2'`)를 기준으로 **`targetPrefix + '교사그룹'`**(예: **`'2026-2교사그룹'`**) 시트명을 생성합니다.
   - 시트 탐색 시 현재 학기의 `<targetPrefix>교사그룹` 시트를 우선 조회하고, 해당 시트가 없을 경우 `'2026-2교사그룹'` 또는 `'교사그룹'` 시트가 존재하면 호환 조회합니다.

2. **시트 데이터 구조 및 유연한 파서 (`parseTeacherGroupsFromSheet_(sheet)`)**
   - **시트 저장 포맷**:
     | A열 (그룹명) | B열 (교사명단) | C열 (교사수) | D열 (수정일시) |
     | :--- | :--- | :---: | :---: |
     | 부장교사 | 김동진, 박수빈, 이민지, 정현우 | 4 | 2026-11-04 15:51:00 |
     | 1학년부 | 박수빈, 최유진, 한승우 | 3 | 2026-11-04 15:52:10 |
   - **양방향 호환 파싱**:
     - 사용자가 웹앱에서 저장한 경우뿐만 아니라 스프레드시트의 `'2026-2교사그룹'` 시트에서 직접 행을 추가·수정한 경우도 모두 인식합니다.
     - B열에 쉼표(`,`)·공백·슬래시(`/`)로 구분된 문자열(`"김동진, 박수빈"`)이 들어있는 형태와, B열·C열·D열... 각 셀에 교사 성명을 1명씩 나열한 형태를 모두 지원하며 `cleanTeacherIdentity_()`를 통해 정규화된 교사 키 배열로 반환합니다.

3. **전체 시간표 페이로드(`buildTimetablePayloadFromRealSheets_`) 연동**
   - 페이로드 반환 객체에 `teacherGroups` 배열(`[{ name: '부장교사', teachers: ['김동진', '박수빈', ...] }, ...]`)과 `foundSheets.teacherGroupSheet` 정보를 포함합니다.
   - `computePayloadSignature_(classes, teachers, meta, teacherGroups)` 해시 계산에 `teacherGroups`를 포함하여, 스프레드시트에서 `'2026-2교사그룹'` 시트가 수정되면 백그라운드 동기화(`checkAndRefreshIfChanged`) 시 즉시 감지·반영되도록 구성합니다.

4. **교사 그룹 저장·삭제 서버 RPC 함수 추가 (`Code.gs`)**
   - **`saveTeacherGroupOnServer(requestJson)`**:
     - 전달받은 `{ prefix, groupName, teachers }` 데이터를 바탕으로 스프레드시트에서 `<prefix>교사그룹`(예: `'2026-2교사그룹'`) 시트를 찾고, 시트가 없으면 `ss.insertSheet(sheetName)`으로 즉시 새로 생성합니다.
     - 동일한 `groupName`이 이미 있으면 해당 행의 교사 명단을 최신 명단으로 업데이트하고, 없으면 하단에 새 행을 추가합니다.
     - 시트 저장 후 `clearTimetableCache_()`를 수행하고 갱신된 `teacherGroups` 목록을 반환합니다.
   - **`deleteTeacherGroupOnServer(requestJson)`**:
     - 전달받은 `{ prefix, groupName }`에 해당하는 그룹 행을 시트에서 삭제하고 캐시를 무효화한 뒤 갱신된 `teacherGroups` 목록을 반환합니다.

### Step 3. 원클릭 그룹 선택/해제 및 0ms 낙관적(Optimistic) 저장 로직 (`index.html`)

1. **원클릭 그룹 선택 (`toggleTeacherGroup(groupName)`)**
   - `n×10` 배열의 그룹 버튼(예: `'부장교사'`)을 클릭하면:
     - 해당 그룹에 포함된 교사들(현재 학기 `data.teachers`에 존재하는 유효 교사)이 **전원 선택 상태가 아니라면**: 그룹 소속 교사 전원을 선택 목록(`state.sharedFreeTeachers`)에 즉시 반영하여 **공유 공강 시간표**를 렌더링합니다.
     - 이미 해당 그룹의 교사 전원이 선택되어 있는 상태에서 **다시 클릭하면**: 해당 그룹 교사들을 선택 목록에서 일괄 해제합니다.
   - 그룹에 속한 교사 전원이 현재 선택되어 있으면 해당 그룹 버튼에 `.active` 클래스가 자동 부여되어 시각적으로 활성 표시됩니다.

2. **교사 그룹 추가·저장 (`saveSelectedTeachersAsGroup()`) 및 삭제 (`deleteTeacherGroup(groupName)`)**
   - **유효성 검사**:
     - 선택된 교사(`state.sharedFreeTeachers`)가 0명이면 `"먼저 아래 교사 목록에서 그룹으로 저장할 선생님을 1명 이상 선택해 주세요."` 안내 메시지를 표시합니다.
     - 그룹 이름이 비어 있으면 입력창에 포커스를 이동하고 이름 입력을 안내합니다.
   - **0ms 즉시 반영 + `'2026-2교사그룹'` 시트 영구 저장**:
     - 저장 즉시 클라이언트 `state.data.teacherGroups` 및 브라우저 `localStorage`에 반영하여 지연 시간(0ms) 없이 `n×10` 그리드에 새 그룹 버튼을 렌더링합니다.
     - 동시에 `google.script.run.saveTeacherGroupOnServer(...)`를 호출하여 현재 활성 학기(예: `2026-2`)의 **`'2026-2교사그룹'`** 시트에 자동 생성·기록합니다.

3. **상단 타이틀 및 내보내기(XLSX / HWPX / PDF) 연동**
   - 특정 교사 그룹과 정확히 일치하는 교사들이 선택된 경우, 공유 공강 시간표 우측 헤더(`#headerSubRole`) 및 엑셀/한글 내보내기에 그룹 이름(예: `부장교사(8명) | *수*, *진*...`)이 함께 표시되어 인쇄·문서 공유 시에도 어떤 교사 그룹의 공유 공강인지 한눈에 확인할 수 있도록 개선합니다.
